Into Lightroom
Turn a LUT into a profile
  1. Open any photo in Camera Raw (Photoshop: Filter → Camera Raw Filter).
  2. Presets panel → ⋯, hold Alt → Create Profile.
  3. Tick Color Lookup Table, load the .cube, set Space: sRGB, untick everything else.
  4. Restart Lightroom. It's in the Profile Browser, for JPGs and raws.
On raw files
Set the base profile to Camera Standard first if your old edits were in-camera JPGs. That's the closest match to the camera's own rendering.
A LUT holds colour only
If a chart shows grain or a vignette, add those with Lightroom's Effects sliders.
